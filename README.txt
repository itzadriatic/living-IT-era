ADRIAN PHILIPPE E. ROM — PERSONAL WEBSITE

Files:
- index.html      Home
- about.html      Personal information
- resume.html     Education
- services.html   Interests
- gallery.html    Photos
- testi.html      Reflection
- contact.html    Contact form
- style.css       Responsive styling
- script.js       Small interaction for the demo contact form
- PHOTOS/         Your uploaded photographs

HOW TO VIEW:
1. Keep the HTML files, style.css, script.js, and PHOTOS folder together.
2. Open index.html in a web browser.
3. Use the navigation menu to test every page.
4. Test the contact form by entering sample information.

NOTE:
The contact form is intentionally a front-end demonstration and does not send data to a real server.

Background music: Muli (Secret Verse).mp3
The site uses a persistent parent shell and iframe-based page navigation so background music continues while moving between sections. Click the music button once to start playback; browser autoplay rules may prevent automatic playback on first load.
